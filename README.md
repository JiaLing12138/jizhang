# 我的记账 · 家庭台账

两个纯前端网页应用，数据存在浏览器本地（localStorage），无后端、无账号。

- `index.html` — 家庭台账（借出款 / 存款 / 大件资产 / 家庭净值）
- `personal.html` — 个人记账本（收支流水 / 攒钱目标 / 资产账户 / iOS 快捷指令 OCR 预填 / 豆包 AI 识别）

## 使用

把两个 HTML 文件用浏览器打开即可（也可部署到任意静态托管，如 GitHub Pages）。

## 快捷指令

个人记账本支持 iOS 快捷指令：截屏 → 提取文字 →（可选）豆包 AI 结构化识别 → 打开
`personal.html?ocr=<编码文字>&ai=<编码JSON>` 自动预填，人工确认后保存。
快捷指令文件与生成脚本在本仓库工作区，不随网页发布。
