# iOS 快捷指令（记账 OCR）

三个快捷指令均已完成苹果签名（`shortcuts sign --mode anyone`），iPhone 直接 AirDrop 或从"文件"App
打开即可导入（首次导入可能提示"不受信任的快捷指令"，去 设置 → 快捷指令 → 允许不受信任的快捷指令 打开即可）。

## 选哪个？

| 文件 | 定位 | 说明 |
|------|------|------|
| `记账OCR豆包.shortcut` | **日常正式版**（推荐） | 截屏 → 豆包 AI 提取金额/分类/备注/日期 → 页面预填待确认；豆包失败自动退回本地规则。需安装豆包 App |
| `记账OCR.shortcut` | 备用版 | 纯本地规则识别，不依赖豆包 App |
| `记账OCR豆包-调试.shortcut` | 诊断用 | 正式版 + 弹窗显示豆包原始输出，排查问题用 |

## 怎么用

1. 先打开记账页面确认能访问：`https://JiaLing12138.github.io/jizhang/personal.html`
2. 导入上面其中一个捷径（删掉旧的同名捷径再导入新的）
3. 在微信/支付宝账单页 **背面双击**（或手动运行捷径）触发
4. 页面自动打开并预填金额/分类/备注/日期 → 核对后点保存

## 工作方式

- 截屏 → 裁掉顶部状态栏 → 提取文字 →（豆包版）带提示词问豆包 → 把原文+AI 结果编码进 URL
- 页面解析参数后立即清空地址栏（隐私），失败自动退回本地关键词规则

> 快捷指令由 `scripts/gen_shortcut.py` 生成（改分类/提示词后重跑并重签），
> 生成后的文件同步提交到本目录。
